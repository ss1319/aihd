🛠️ 前端修改详细教程

教你自由修改网站所有细节

📁 网站文件结构

网站由以下文件组成，每个文件负责不同功能：

  • index.html — 首页（目录页+搜索框+分类列表）
  • pages/ — AI单页文件夹（每个AI一个HTML文件）
  • assets/img/ — 图片文件夹（赞赏码、公众号二维码）
  • xgsc.html — 本教程页
💡 所有文件都是纯HTML，用任何文本编辑器（记事本、VS Code等）都能修改

🎨 修改颜色和主题

金色主题色

找到CSS中的以下代码，修改颜色值即可：

/* 主金色 - 改成你喜欢的颜色 */
background:linear-gradient(135deg,#d4a017,#f4d03f);

/* 标题文字颜色 */
color:#8b6914;

/* 滚动条颜色 */
::-webkit-scrollbar-thumb{background:#d4a017}

/* 页面背景渐变 */
body{background:linear-gradient(135deg,#fff8e7,#ffe9b8,#fff3d6);}

🔍 修改搜索源

在index.html中找到 var urls 部分，修改搜索接口：

var urls={
  video:'https://search.bilibili.com/all?keyword='+enc,  // B站视频
  music:'https://music.163.com/#/search/m/?s='+enc,     // 网易云音乐
  bing:'https://cn.bing.com/search?q='+enc,              // 必应搜索
  article:'https://weixin.sogou.com/weixin?type=2&query='+enc,  // 搜狗微信
  image:'https://image.baidu.com/search/index?tn=baiduimage&word='+enc,  // 百度图片
  so:'https://www.so.com/s?q='+enc                       // 360搜索
};
⚠️ 注意：不是所有网站都能在iframe中显示，百度/头条等会拒绝嵌入

🤖 增加新AI页面

步骤1：创建新HTML文件

在pages文件夹中新建一个HTML文件，文件名用英文小写，比如 myai.html

步骤2：复制模板代码

复制任意一个现有AI页面的代码，修改以下内容：

  • 修改 <title> 中的名称
  • 修改 <h1> 中的AI名称
  • 修改 href="官网地址" 中的链接
  • 修改介绍文字、用途、步骤、代码、链接

步骤3：在首页添加入口

在index.html的 cats 数组中添加：

// 在对应分类的 items 数组中添加：
{n:"我的AI",f:"myai",i:"🤖",d:"AI简介"}

⚓ 修改悬浮按钮

三个悬浮按钮的样式代码：

/* 🏠 返回主页 - 橙红渐变 */
.home-fab{background:linear-gradient(135deg,#f39c12,#e74c3c);color:#fff}

/* 💬 客服 - 紫蓝渐变+跳动动画 */
.svc-fab{background:linear-gradient(135deg,#9b59b6,#3498db);color:#fff;animation:bounce 1.2s infinite}

/* 🚀 返回顶部 - 青绿渐变 */
.back-top{background:linear-gradient(135deg,#1abc9c,#2ecc71);color:#fff}

/* 按钮大小 - 修改32px为你想要的尺寸 */
.fab{width:32px;height:32px}

📝 修改字体大小

/* 正文 - 默认16px */
.section p{font-size:16px;line-height:2}

/* 页面大标题 - 默认32px */
.header h1{font-size:32px}

/* 小标题 - 默认20px */
.section h2{font-size:20px}

/* 代码块 - 默认14px */
.code-box pre{font-size:14px}

📤 如何上传修改到GitHub

方法1：GitHub网页上传（最简单）

  • 打开 https://github.com/ss1319/aihd
  • 点击 Add file → Upload files
  • 拖拽修改后的文件
  • 点击 Commit changes
  • 等待1-2分钟，刷新 https://ss1319.github.io/aihd/ 看效果

方法2：GitHub Desktop（桌面软件）

  • 打开 GitHub Desktop 3.5.4
  • 选择 aihd 仓库
  • 修改文件后，左侧会显示变更
  • 填写修改说明，点击 Commit to main
  • 点击 Push origin 上传
  • 等待1-2分钟看效果

🔧 常用修改速查

  • 改AI名称：搜索名称，替换成新名称
  • 改官网链接：搜索旧链接，替换成新链接
  • 改简介：找到对应介绍段落，直接修改文字
  • 改图标：把emoji图标（🤖）换成你喜欢的emoji
  • 改按钮颜色：找到对应CSS类，修改渐变色
  • 改滚动条粗细：把 width:1px 改成你想要的粗细
💡 修改后按 Ctrl+S 保存，然后上传到GitHub，等待2分钟刷新即可看到效果
